# Vortex-Bessel physical error models

## Purpose

This branch replaces report-atlas shortcuts that treated several different
physical errors as generic phase ramps or single-plane image changes.  Physical
errors are now inserted at the optical plane where they occur.

The source-scale route remains

`input beam -> SLM1 -> SLM2 -> common 4F/+1 order -> axicon -> free-space`

with no additional nominal 1.8 mm real-space objective pupil.

## Input beam angle

A mispointed collimated input beam is represented before SLM1 by

`E(x,y) = A(x,y) exp[i (kx x + ky y)]`,

with

`kx = k sin(theta_x)`, `ky = k sin(theta_y)`.

The tilted field is then passed through both SLMs and the Fourier-order filter.
This is physically different from adding a linear phase after the axicon,
because the changed incident spatial spectrum interacts with the SLM carrier
and finite 4F passband.

## Input beam radius and decentre

Beam radius and lateral displacement modify the Gaussian amplitude before SLM1.
The full SLM/4F chain is rebuilt for every sweep value.  The earlier visual-atlas
implementation, which reweighted the field after the 4F chain, is superseded for
physical parameter studies.

## Axicon decentre

Axicon decentre translates the physical sag profile relative to the incoming
field.  The conical phase is therefore evaluated from a shifted local radial
coordinate rather than shifting the propagated image afterwards.

## Axicon tilt

A rigidly tilted axicon is not represented by a simple steering phase.  The
implemented model rotates the optic reference plane, solves the intersection of
lab-z incident rays with that plane, evaluates local optic coordinates, and
applies the resulting conical optical-path difference.  A `1/|a_z|` path factor
accounts for the increased path through the thin element.

This is explicitly a **small-angle rotated thin-element OPD model**.  It captures
the projected/elliptical conical geometry and therefore the leading wavefront
aberration missing from the old linear-ramp model.  It is **not** a full vector
Snell/Fresnel model of both physical surfaces at large angle.  The implementation
refuses rigid-body tilts above 5 degrees so that the approximation is not silently
used outside its intended regime.

Relevant literature reports that oblique illumination / tilted axicons broaden
and aberrate the Bessel focal line and can require elliptical-axicon correction:

- A. Thaning, Z. Jaroszewicz, A. T. Friberg, *Diffractive axicons in oblique
  illumination: analysis and experiments and comparison with elliptical
  axicons*, Applied Optics 42, 9-17 (2003), DOI 10.1364/AO.42.000009.
- H. Cheng et al., *Aberration correction for SLM-generated Bessel beams
  propagating through tilted interfaces*, Optics Communications 475, 126213
  (2020), DOI 10.1016/j.optcom.2020.126213.

## Rounded axicon tip

For an ideal sharp axicon the shallow-cone sag is

`h(r) = r tan(gamma)`.

A rounded apex is represented by a hyperboloidal profile

`h(r) = sqrt(a^2 + [r tan(gamma)]^2) - a`.

The additive constant is optically irrelevant.  As `a -> 0` the ideal cone is
recovered; near the axis the rounded profile has zero slope.  This is consistent
with the standard hyperboloidal round-tip treatment used in the axicon
literature.

Rounded/blunt tips are known to generate strong axial intensity oscillation and
'droplet' structure for zero-order Bessel beams.  Higher-order/vortex Bessel
beams can be less sensitive because the incident field has reduced central
weight.

Relevant literature:

- J. H. McLeod-style real-axicon analyses and later experimental/theoretical
  work: *Intensity distribution around the focal regions of real axicons*,
  Optics Communications 281, 4240-4244 (2008), DOI
  10.1016/j.optcom.2008.05.027.
- R. Sahin, *Bessel and Bessel vortex beams generated by blunt-tip axicon*,
  Turkish Journal of Physics 42, 47-60 (2018), DOI 10.3906/fiz-1707-8.
- V. Yu. Mylnikov and G. S. Sokolovskii, *Droplet quasi-Bessel beam generated
  with the round-tip axicon: Exact solutions for different axicon shapes*,
  Optik 268, 169797 (2022), DOI 10.1016/j.ijleo.2022.169797.

A separate `flat_blunt` profile is provided for sensitivity to a truly truncated
flat centre.  It is not a claim about the actual lab optic unless microscopy or
manufacturer metrology supports that shape.

## Generic Zernike aberrations

Defocus, astigmatism, coma and spherical terms remain in the atlas, but they are
now labelled **generic wavefront-error sensitivity at the axicon plane**.  They
answer the question 'what if the field arriving at this plane contains this RMS
wavefront error?' They must not be described as the physical consequence of a
specific misaligned axicon, input beam, iris, or other optic unless a separate
optical model derives that Zernike content.

## Figure policy

A single x-y plane at 60 mm is insufficient for diagnosing many Bessel-beam
errors.  Sweep figures now include:

1. a tight shared-scale x-y map at a representative plane;
2. a shared-scale x-z propagation map over the Bessel formation region;
3. an x-y difference map relative to the nominal member of the sweep.

Display interpolation is not used for metrics.

## Calibration blockers

The following remain calibration-required before claiming that a simulated error
magnitude equals the lab error magnitude:

- actual Gaussian radius at the relevant input plane;
- input beam pointing angle and lateral offset;
- physical axicon clear aperture;
- axicon rigid-body tilt and decentre;
- actual apex profile / rounding parameter or flat-tip radius;
- refractive index of the real axicon at 1029 nm;
- camera physical pixel scale.

The simulations can therefore support controlled relative sensitivity and visual
failure signatures before calibration, but measured-to-simulated absolute error
matching remains blocked until these values are obtained.
