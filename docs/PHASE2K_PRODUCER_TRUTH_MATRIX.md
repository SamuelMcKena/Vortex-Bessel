# Phase 2K — Producer Truth Matrix

This matrix is the control document for regenerating the repository.  It is
**producer-first**: a figure is not considered trustworthy because the PNG looks
reasonable.  An output family can be regenerated for scientific use only when
its producing model passes the appropriate analytic/reference, independent
numerical, convergence and hardware-provenance gates.

Status vocabulary:

- **GREEN (mathematical core)** — the stated equation/identity has an independent
  truth test. This does not imply bench calibration.
- **YELLOW** — useful numerical model, but one or more convergence, model-scope or
  physical-parameter gates remain.
- **RED / QUARANTINED** — existing outputs cannot be used quantitatively.
- **GOVERNANCE ONLY** — evidence about readiness/limitations, not a beam prediction.

## Hard rule for figure selection

The eventual thesis/presentation figure table will contain only figures whose
row in this matrix has reached the required truth state for the claim being
made.  A clean numerical illustration may be acceptable while still marked
"nominal/calibration-blocked" if the caption says exactly that; a figure may not
be described as measured, bench-calibrated, physically predictive or
experimentally validated unless the corresponding gate has actually passed.
