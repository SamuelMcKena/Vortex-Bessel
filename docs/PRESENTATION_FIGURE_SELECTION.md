# Presentation figure selection — Phase 2I audit

This document records the presentation-facing figure selection after auditing the tracked figure inventory and current figure-producing code on the `phase2i-experimental-bench-closure` line.

The presentation is intentionally **not** a catalogue of every figure in the repository.  The six-minute story is:

> actual system model → programmable B0/V1/V3 beam profiles → realistic errors → two concrete axicon examples → simulation/experiment closure and inverse correction.

The selected figures below are generated from current repository physics on the isolated `presentation-figure-audit-phase2i` branch.  They do not replace accepted Phase 2A–2I evidence.

### 3. Moving towards the real experimental system

**Primary:** `outputs/figures/presentation_phase2i/08_V1_real_error_fingerprints.png`

Why it replaces the boxes-only error-scope diagram:
- every column is generated by the current physical forward route;

- shows both transverse and fixed-laboratory longitudinal signatures;

**Do not present the chosen perturbation magnitudes as measured bench tolerances.** They are illustrative sensitivity cases.

### 4. Example 1 — axicon lateral decentre

### 5. Example 2 — non-ideal axicon tip

**Primary:** `outputs/figures/presentation_phase2i/05_V1_nonideal_tip_fixed_lab.png`

Why it survives:

**Optional small secondary panel / appendix:**
`outputs/figures/presentation_phase2i/09_tip_avoidance_planning_proxy.png`

This is useful only with its explicit boundary:
- annular illumination is a **planning proxy** applied at the axicon plane;
- power is equalised only for morphology/tip-loading comparison;
- it is **not** yet a calibrated phase-only SLM implementation or an efficiency prediction.

The proxy reduces the fraction of incident power falling inside the chosen 200 µm central tip region from about 1.44% to 0.34% for the tested target illumination, but the amplitude-encoding cost and hardware implementation remain separate questions.

### 6. Where this is going — experiment ↔ simulation ↔ correction

**Hero evidence:** `outputs/figures/presentation_phase2i/10_synthetic_zstack_inverse_recovery.png`

**Supporting loop:** `outputs/figures/presentation_phase2i/06_simulation_experiment_closure.png`

Why this is stronger than a generic final workflow slide:
- #10 demonstrates, in code, the central inverse idea rather than merely drawing it;
- a hidden +300 µm axicon decentre is recovered exactly from a 17-plane synthetic V1 z-stack by sweeping the same physical parameter through the forward model;
- the repository's fixed-plane minimum of 16 z planes was retained rather than weakened;
- #06 then shows where real measurement enters and how the inferred state feeds correction/update.

**Critical claim boundary:** #10 is synthetic model-to-model validation.  It is not an experimental aberration reconstruction and must be labelled as such.  The experimentally useful next step is to replace the synthetic target stack with calibrated Beamage data and fit a low-dimensional physical parameter vector before generating an additive SLM correction.

## Figures not recommended for the six-minute core

- Phase 2C scalar/vector and Debye component plots: strong reference/appendix evidence, but too far downstream for this six-minute narrative.
- 3-D intensity surfaces: visually impressive but lower information density than x-y + x-z for the questions being asked.
- dense Phase 2E diagnostic sheets: scientifically useful, but too crowded for a live slide.
- Nathan / H1 vector-hexagonal evidence: valuable separate research scope, but it distracts from the Bessel/vortex-Bessel + bench-closure story here.
- Stage 9 / nominal CSLM candidate atlases: historical development evidence rather than the current Phase 2I presentation state.
- material-response / weld proxy figures: retain for a later processing/results talk unless directly supported by calibrated experimental response data.  This presentation should finish at trusted field control and the path to processing rather than imply uncalibrated optical intensity is a weld prediction.

## Presentation claim rules

1. Use fixed-laboratory x-z evidence; no per-z recentering for diagnostic claims.
2. Keep illustrative perturbation values distinct from measured bench calibration.
3. Do not fabricate an experimental image to fill an empty comparison panel.
4. Treat the tip-avoidance figure as a planning proxy unless a calibrated phase-only implementation is demonstrated.
5. Treat the z-stack inverse figure as synthetic proof-of-principle until real calibrated camera data is fitted.
6. Correction should be additive residual-wavefront correction, not conjugation of the complete structured field, so the intended vortex phase is preserved.
