# q=20 Bessel z-scan: phase-reconstruction physics lock

## Why this document exists

The experimental q=20 analysis has two deliberately different paths:

1. a **presentation/diagnostic path**, which is conservative and only claims the
   recoverable non-axisymmetric residual when absolute calibration is absent; and
2. the **authoritative correction path**, which implements the Bessel-specific
   phase-retrieval method needed to recover both angular and radial phase error
   before an SLM2 correction can be proposed.

The old 2-D correction visualisation made by mapping measured z-order directly to
normalized radius is legacy diagnostic material only. It is not an SLM phase
reconstruction and is not consumed by the active closed-loop controller.

## One transverse wavefront, not a longitudinal mask

For an axicon-generated Bessel beam, each measured focal-line position samples a
different annulus of one transverse input field. There is therefore one residual
input-plane wavefront

\[
\psi_{\rm res}(\rho,\theta),
\]

not an independent correction at every longitudinal camera plane. The desired
phase-only correction in the appropriate conjugate plane is

\[
\phi_{\rm corr}(\rho,\theta)=-\psi_{\rm res}(\rho,\theta),
\]

and all later z-dependence is generated by propagation.

For the simple ideal cone,

\[
\rho_z=z\tan\alpha,\qquad k_\perp=k\tan\alpha.
\]

The full retrieval does not assume one fixed measured `k_perp` for every plane.
Instead it optimizes `k_perp` separately at each z, as in the retrieval procedure
of Miao *et al.*

## Programmed vortex versus aberration

The target q=20 vortex is deliberate beam structure, not an aberration. The modal
basis is indexed by aberration Fourier order `m`, with Bessel order

\[
n=m-q.
\]

The ideal q-th order Bessel component is therefore `m=0`. Reconstructing the
annular input field from the fitted `m` coefficients factors the programmed
`q*theta` term out of the residual. The correction must never contain the target
vortex phase itself.

## Per-plane transverse wavenumber and radial phase

The authoritative correction path first obtains an optimized

\[
k_{\perp,\mathrm{opt}}(z)
\]

for every measured plane. A ring-derived global value is used only as an initial
seed; it is not forced on the whole z-stack.

Using the stationary-phase mapping, the input-annulus radius for an absolutely
calibrated camera distance is

\[
\rho_z = z\,\frac{k_{\perp,\mathrm{opt}}(z)}{k}.
\]

Relative variation of the fitted transverse wavenumber carries the missing
axisymmetric information. With a nominal/reference transverse wavenumber
`k_perp,nom`, the radial phase gradient is reconstructed as

\[
\frac{\partial\psi_\rho}{\partial\rho}
= k_{\perp,\mathrm{nom}}-k_{\perp,\mathrm{opt}}(\rho),
\]

and numerically integrated across the sampled annuli. The arbitrary global
phase constant is physically irrelevant.

This is different from the presentation-only `q20_phase_physics.py` path. That
module intentionally does **not** infer a radial phase from independently fitted
annular pistons and therefore labels radial piston as unrecovered. The full Miao
retrieval instead obtains radial information from the independently optimized
`k_perp(z)` values.

## Angular phase retrieval

After the per-plane `k_perp` step, the complex Bessel modal coefficients are
fitted with increasing aberration order. The implementation starts at low order
and increases the maximum `|m|` until the fit reaches the cost threshold or
additional modes cease to improve the solution materially. The maximum order is
therefore a convergence ceiling, not a fixed claim that `m_max=8` is always
sufficient.

The recovered complex annular field is converted to angular phase after removing
only the intensity-invisible global piston of each annulus. Wrapped phase is
interpolated through unit phasors rather than interpolating values across the
`-pi/pi` discontinuity.

The total sampled residual is then

\[
\psi_{\rm res}(\rho_i,\theta)
= \psi_\rho(\rho_i)+\psi_\theta(\rho_i,\theta).
\]

## Coordinate handling

The full BMG runner preserves the camera coordinate system across z. It averages
the four repeats at each plane after removing only repeat-to-repeat acquisition
jitter. It does **not** translate each z plane so that the dark vortex core sits
at the same pixel. Genuine beam walk, pointing and coma-like translation are
therefore retained as experimental information.

## Intensity-only conjugate ambiguity

Intensity-only Bessel phase retrieval has a conjugate ambiguity. The two
solutions correspond to conjugated complex fields and a 180-degree rotation of
the reconstructed input intensity. The active correction path therefore refuses
to choose a hardware correction branch from the same focal-line intensity stack
alone.

A branch can be resolved by either:

- an independent input-plane/annular intensity reference; or
- an experimentally known-sign SLM perturbation followed by a second capture,
  provided the perturbation establishes which retrieved branch responds with the
  physically correct sign/parity.

Until that is done, the manifest reports `branch = unresolved` and low-gain SLM2
application is blocked.

## Input plane to SLM2

A phase map reconstructed in the axicon/input reference plane is not automatically
an SLM2 pixel map. Before any trial, the experiment must provide the measured
end-to-end transform:

- input-plane metres per SLM2 pixel;
- SLM2 beam centre;
- rotation;
- x/y parity;
- SLM2 phase LUT/stroke at 1030 nm.

The active code uses those measured quantities explicitly. It does not silently
assume nominal SLM dimensions, relay magnification or parity.

## Active code ownership

### Hardware-correction path

- `miao_full_retrieval.py` — per-plane `k_perp`, adaptive complex Bessel modes,
  radial-phase integration, ambiguity handling and input-plane→SLM transform.
- `run_q20_miao_retrieval.py` — complete 18×4 BMG runner with fixed camera
  coordinates and readiness manifest.
- `q20_hardware_calibration_template.json` — values that must be measured before
  a trial can be generated.
- `iterative_correction_controller_v2.py` — calibrated low-gain trial and
  experimental acceptance controller.
- `iterative_correction_controller.py` — compatibility shim to v2; the legacy
  normalized-z map is no longer used.

### Presentation/diagnostic path

- `q20_phase_physics.py` — conservative non-axisymmetric residual visualisation.
- `rebuild_q20_presentation_from_bmg.py` — measured stack/XZ/YZ and presentation
  figures from the complete acquisition.
- `single_transverse_phase_forward_test.py` — one-input-phase model falsification
  diagnostic. Its final exact conjugate column is model closure, not experimental
  proof of correction.

## Readiness gates

The active correction pipeline may fit local per-plane quantities before all
hardware calibration is known, but a low-gain SLM2 trial remains blocked until:

1. absolute camera-z to axicon/input-reference distance is measured;
2. the direct/conjugate branch is resolved independently;
3. input-plane→SLM2 scale, centre, rotation and parity are measured;
4. the SLM2 1030-nm phase LUT/stroke is calibrated.

Even after those gates pass, the result is only **trial-ready**. Final acceptance
requires applying a conservative low-gain candidate, acquiring a new identically
sampled 18-plane × 4-repeat BMG stack, and passing the measured before/after
acceptance criteria. A model prediction cannot accept its own correction.

## Presentation language

For the current existing figures use labels such as:

- **Measured q=20 BMG stack**
- **Measured x-z / y-z evolution**
- **Retrieved non-axisymmetric residual phase (model-inferred)**
- **Single-transverse-phase forward-model diagnostic**

For a later full-retrieval figure, once the required calibration exists, use:

- **Miao-style reconstructed input-plane residual phase**
- **Predicted conjugate SLM2 correction (calibrated transform)**

Do not call any simulated corrected result an experimentally corrected beam until
a new post-mask camera stack has actually been acquired.
